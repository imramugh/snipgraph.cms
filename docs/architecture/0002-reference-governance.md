# ADR 0002: Reference conformance is designed in

Status: accepted

The product-independent reference kit defines the feature packet and catalog
identity conventions. Product catalogs describe screens, flows, patterns, and
blocks. A feature is ready only after it cites applicable references or adds the
missing specification.

CI validates structure and references as a quick guardrail. It is not the first
time feature design, data requirements, or acceptance behavior are considered.
