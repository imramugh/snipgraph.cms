# pattern.admin-typography.v1

Administrative interfaces use a restrained type hierarchy. Body copy and form
values use regular weight; labels and controls use medium weight; headings use
semibold weight. Bold is reserved for exceptional emphasis, never used as the
default text treatment. Size, spacing, colour, and position establish hierarchy
before weight.

The system uses a privacy-preserving system sans-serif stack, a minimum body
line-height of 1.5, and visible focus styles. Dense metadata may be smaller but
must retain sufficient contrast and must not rely on uppercase text alone.
