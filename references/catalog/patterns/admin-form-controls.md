# pattern.admin-form-controls.v1

Admin controls use a shared minimum height, generous inline padding, a readable
line height, and an inset focus ring that does not move surrounding content.
Labels sit outside the control surface and help text follows the control. Error,
disabled, and dark-appearance states retain the same geometry.

Font family fields use a searchable combobox backed by the Google Fonts catalog.
The menu previews a bounded set of visible families in their own typeface and
communicates category and available weight range. Selecting a family immediately
reconciles the role's selected weights with the weights that family publishes.

Semantic color fields open a popover containing a two-dimensional saturation
surface, hue control, previous/current comparison, exact six-digit hexadecimal
entry, and reusable theme swatches. The hexadecimal value remains the canonical
stored representation.
