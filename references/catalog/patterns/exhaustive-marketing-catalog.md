# pattern.exhaustive-marketing-catalog.v1

The Marketing catalog is exhaustive but role-aware. Licensed examples are
represented by stable product-owned identifiers and structured capabilities;
licensed filenames and source code are never runtime dependencies. The
catalog must account for 133 page sections, 31 site elements, five system
treatments, and ten composed recipes.

Page sections are selected as a semantic family followed by a visual variant.
Content fields belong to the family, while layout, media placement, alignment,
surface treatment, and responsive behavior belong to the variant. Adding a
variant must not create a second content model when the underlying meaning is
the same.

Site elements configure persistent chrome, system treatments configure
framework-owned screens, and page examples are editable recipes. These roles
must not appear as interchangeable options in one undifferentiated picker.
