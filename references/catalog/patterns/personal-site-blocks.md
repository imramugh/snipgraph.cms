# pattern.personal-site-blocks.v1

The initial personal-site catalog covers introduction, long-form copy, feature
or service grids, projects, statistics, testimonials, client or partner logos,
contact details, reusable imagery, and calls to action. Each block represents a
semantic content role rather than a fixed page position.

Variants remain deliberately constrained. Authors choose structured content and
a small presentation option where it changes meaning; arbitrary classes, HTML,
and pixel-level layout controls are excluded. Public renderers draw structural
direction from the licensed Tailwind Plus Marketing UI kit while preserving the
project's own tokens and accessibility requirements.
