# screen.site-settings.v1

Use for configuring the shared public-site shell: identity, navigation, footer,
social profiles, default metadata, and redirects. A local vertical section
navigation keeps the long form scannable; each section uses explanatory copy
beside a constrained field column. Keep draft and publication state visible in
the contextual inspector.

Saving creates an immutable settings draft; applying settings to the live site
requires a separate publish action. Navigation, social links, and redirects are
ordered repeaters with explicit add, remove, and reorder controls. Required
states: ready, saving, validation failure, revision conflict, unpublished draft,
and published.
