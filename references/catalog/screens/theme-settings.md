# screen.theme-settings.v1

The theme settings screen extends the existing site-settings workspace with
Typography, Palette, and Named schemes destinations in its vertical section
navigation. Authors edit the draft and see
a representative live sample containing display text, body text, actions,
muted content, and inverse content before saving.

Font controls use a searchable Google Fonts catalog with live family previews and
offer only weights published for the selected family. Color controls use the rich
picker in `pattern.admin-form-controls.v1` while retaining an exact hexadecimal
value as the saved representation.
Validation issues identify the semantic role and color pair that needs
attention. Theme changes follow the same Save draft and Publish settings
actions as identity, navigation, SEO, and redirects.
