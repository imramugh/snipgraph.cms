# screen.reference-catalog.v1

Use for discovering and evaluating governed product patterns. The screen is a
visual workbench, not a documentation index: category navigation and search
select a specimen; a large preview canvas shows the artifact; controls expose
meaningful variants and desktop, tablet, or mobile width; the stable reference
ID and concise usage guidance remain adjacent supporting information.

Content blocks render through the production block renderer with deterministic
representative content. Screens use recognizable miniatures, while flows use
directional diagrams and interaction patterns use state-based specimens. Never
substitute a prose-only card where a visual example can communicate structure,
hierarchy, state, or responsive behavior.

The catalog is read-only. It must not expose licensed source files, source
filenames, administrative data, or mutation controls. Selection and preview
settings are ephemeral and do not become CMS content.
