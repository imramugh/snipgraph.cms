# screen.content-list.v1

Use for browsing one content type. It includes a clear page title, primary create
action, text search, status filtering, sortable updated date, draft/published
state, and an empty state that teaches the first action. Use a responsive table
with stacked mobile columns. Row activation opens the editor; secondary actions
remain in an explicit menu.

Required states: loading, empty, populated, filtered-empty, unavailable, and
permission denied. On narrow screens, retain title, status, updated time, and the
primary action before secondary metadata.
